# 「微缩营地巡游」网页端三渲二房车营地小玩具 · 制作提示词

请制作一个运行在网页端的三维微缩小玩具：以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观陈列盒。观看者可以随时在「场景、车型、时间、天气」四个维度之间自由切换与组合，把同一个微缩世界玩出许多种样子；默认启动组合为「海崖 · C型房车 · 黄昏 · 晴朗」，即以原始设计的黄昏海崖房车营地作为第一眼印象。画面风格为三渲二，强调浓厚的日式二次元动画氛围。以下分点描述全部要求。请特别注意：本提示词带有硬性的工作流程约束（详见第九节）——读完需求后先产出实现文档、经用户审阅同意后才能开始实现；开发全程仅使用内置浏览器打开与调试；实现过程中须按需对照本提示词复盘；删除与清理文件必须遵守第九节第四点的安全红线；所有项目文件与文档统一写入当前工作目录下新建的项目目录内，git 仅做本地提交、不涉及任何远程仓库。

## 一、整体形式与美术总纲

1. 形式：网页端交互式三维小玩具（微缩模型陈列盒）。第三视角环绕观察，可自由拖拽旋转、滚轮缩放观看，触屏同样支持。
2. 画面风格为三渲二：高精细建模、三渲二卡通渲染、清晰的轮廓线（描边明确）、细腻但简洁的材质层次、材质表现干净、色彩柔和但富有层次感，强调浓厚的日式二次元动画氛围与二次元夏日旅途场景感。
3. 每个场景的地面都为一个完整的正方形底座，所有元素都搭建在这个底座上，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。不同场景更换底座的材质与边缘处理，但"微缩底座"的形式统一。
4. 本玩具带有一套轻量的UI控制界面，用于切换场景 / 车型 / 时间 / 天气（详见第六节）；除这套UI外，画面本身不出现其他HUD类杂乱元素，模型本体保持纯净的陈列感，并提供"隐藏UI"入口以回到纯粹的观赏模式。
5. 整体气质：安静、治愈、带一点旅途黄昏的辽阔孤独感但依然温暖，像一幕幕被定格下来的日本动画场景模型。这一气质适用于所有场景，包括末世场景——末世也要画得干净、有秩序感与生活气息，不追求写实血腥或恐怖。
6. 不要人物。生命的温度全部由场景道具、车内陈设与动效来承载。

## 二、场景系统（首发4个场景，架构上可继续扩展）

场景与车型、时间、天气完全解耦：任何车辆可以停在任何一个场景的中央营位，任何一个场景都可以在任何时间与天气下观看。每个场景 = 一块正方形底座 + 环境元素 + 场景专属动效 + 场景专属色彩基调（再被时间与天气系统调制）。

### 2.1 海崖营地（默认场景）

- 地形与构图：悬崖草坪上的临崖营位，停放的车辆位于底座视觉中心。营地不需要太大，但要有明确的"临崖观海"构图，像日本动画里常见的夏末旅行一幕。
- 营地元素：遮阳天幕与折叠桌椅、串灯、烧烤炉、野餐垫、小营地灯、防水地垫、连接水电桩的管线、营位旁的小型折叠自行车、木栈道、崖边护栏、观景长椅、路牌、海草与礁石、通往小海湾的石阶、远处海面上的小型帆船与防波堤灯塔等。
- 色彩基调：日落金橙与海面蓝紫渐变的层次感、海面粼粼波光与天边晚霞渐变、（黄昏时）暖色车内灯光与冷色暮色海景的鲜明冷暖对比，营造出非常典型的日式动画公路旅行氛围。

### 2.2 山间松林营地

- 地形与构图：一片被高大层叠松林环抱的林间空地碎石营位，停放的车辆位于视觉中心，四周松树高低错落、树冠层叠。
- 营地元素：两树之间的吊床、篝火堆与环形原木凳、木质营位平台与林间木阶步道、山涧小溪与跨溪小木桥、指路木牌、树干上的鸟屋与防熊食物储藏箱、苔藓蕨类与蘑菇丛、垒起的柴堆、晾晒的毛巾、溪边的打水桶与水瓢、远处层叠山脊与山腰云带、林间空隙洒下的斑驳光斑。
- 色彩基调：森林绿与晨雾青白，光斑与雾气随时间变化；构图强调"林间静谧"，像日本动画里夏日山林露营的一幕。

### 2.3 末日避难所营地

- 地形与构图：废土上一处被加固的营地，车辆停在硬化地面的视觉中心，四周被工事与围墙半包围。
- 营地元素：混凝土掩体与厚重的防爆门、铁架瞭望塔与探照灯、沙袋工事、锈蚀集装箱与波纹铁皮围墙、缠绕的铁丝网、废旧汽车残骸与轮胎堆、油桶与手写警示牌、净水装置与冒着蒸汽的发电机、拼装的太阳能板阵列、旋转的雷达天线、火堆上架着的油桶改造烧烤架、晾衣绳上晾着的工装、远处断裂的高架桥与荒废城市剪影。
- 色彩基调：锈红、沙黄与混凝土灰，点缀火光与冷色荧光；构图强调"废土据点"，像日本动画里末世旅人的中转补给站，依然是干净画风的治愈系末世。

### 2.4 高速路服务区

- 地形与构图：服务区一角带划线车位的停车区，车辆停在视觉中心的房车专用大车位上。
- 营地元素：加油站雨棚与加油机、便利店与发光招牌、门口的自动售货机（货道排列可见）、电动车充电桩、餐饮区明亮的大玻璃窗、遮阳连廊与公共步道、行道树与绿化带、公路主线与护栏、高速路牌与出口指示牌、长椅与分类垃圾桶、洗手池、旗杆上飘动的小旗。
- 色彩基调：柏油灰 + 便利店暖光 + 行道树绿，夜间以招牌灯箱、售货机灯光与主线车流灯光为主角；构图强调"旅途驿站"，像日本动画里深夜或清晨在"道の驿"停靠补给的一幕。

### 2.5 场景扩展能力（硬性架构要求）

场景必须以注册表 / 模块化方式实现：每个场景是独立模块（地形、道具布置、场景动效、色彩基调、光照钩子），在场景注册表中登记即可被UI与切换逻辑识别。新增场景不应修改核心渲染与切换代码，只需新增模块并注册。

## 三、车型系统（首发5种车型，架构上可继续扩展）

车型与场景解耦，任何车型可出现在任何场景的中央营位；不同车型进入不同场景时允许轻微适配（接地高度、朝向、末世场景下的蒙尘涂装等，不强制）。所有车型都保留"外拓展机构已展开"与"内部可透过车窗 / 帐帘清楚看到"两个核心特征，但不同车型的展开方式、涂装与内饰风格必须有明显差异，细节量不得少于C型房车。

### 3.1 C型房车（默认车型）

- 外部：升顶展开、侧拓展舱滑出，经典C型驾驶舱凸头造型。
- 内部（透过升顶帐帘与大面积车窗清楚看到）：驾驶舱大屏与仪表、卡座餐桌、厨房区的水槽与灶台、冰箱、吊柜、床铺与温暖的小夜灯、侧拓展舱内的沙发与书架。车内要显得明亮、温暖、真实、充实，与室外渐暗的蓝调时刻海天形成鲜明冷暖对比（黄昏时段最明显），营造温馨紧凑的旅居感。

### 3.2 A型大巴式房车

- 外部：方正的大巴式车身、大面积前挡风与贯通侧窗、车顶空调外机与卫星锅、侧裙储物舱门、展开的侧遮阳棚与电动踏步、车尾自行车架与折叠自行车。
- 内部：环形豪华沙发卡座与中岛厨房（双开门冰箱、水槽、嵌入式灶台与烤箱）、通顶吊柜与暖色灯带、木纹地板、半隔断的独立卧室与双人床、小卫浴间（可见洗手盆与淋浴隔断）。整体是"移动小公寓"式的暖木色豪华感，与C型的紧凑温馨形成对比。

### 3.3 拖挂式房车 + 牵引皮卡

- 外部：一辆全尺寸皮卡（货斗里载着行李箱、备用油桶与柴火）牵引一辆流线型白色拖挂房车；到位后拖挂支撑腿放下、遮阳棚展开、拖挂前部的燃气瓶与备胎可见。
- 内部（拖挂车厢两侧大窗可透视）：尾部横置双人床与舷窗、一侧紧凑厨房与吊柜、对坐卡座与可升降小桌板、小卫生间隔断；皮卡双排驾驶舱内可见仪表盘、中控屏与后座的睡袋行李。整体是"车队式"的旅居感。

### 3.4 B型露营面包车（vanlife）

- 外部：圆润紧凑的复古双色面包车、车顶行李架与捆着的冲浪板、侧边遮阳棚、后掀式尾门与纱帘、车身侧面的手绘小贴纸。
- 内部（大侧窗与掀顶帐帘透视）：对坐小卡座与翻折小桌（可变床结构做成半展开状态展示）、迷你厨房（单孔灶、小水槽、迷你冰箱）、车内串灯、挂毯与小盆栽、手冲咖啡具与散落的书。装饰风格慵懒随性，是"自由职业者在路上"的氛围。

### 3.5 越野皮卡 + 车顶帐篷（overlanding）

- 外部：升高底盘与全地形胎的硬派越野皮卡、车顶行李架上的折叠帐篷（已展开、带登车梯与帐篷边LED灯串）、侧边遮阳幕、货斗里的油桶 / 水箱 / 工具箱 / 折叠桌板、车侧爬梯与车顶探照灯。
- 内部（双排车窗透视）：驾驶舱全液晶仪表与中控大屏、后座改装的休憩区（睡袋、摊开的地图、手持对讲机与杂物网兜）。风格硬朗但整洁，是"远征装备控"的细节感。

### 3.6 车型扩展能力（硬性架构要求）

与场景同理：车型也做成注册表 / 模块化。每个车型模块声明：外部模型、展开机构、透视内饰、内饰灯光钩子。新增车型 = 新增模块并注册，不修改核心逻辑。

## 四、时间系统（清晨 / 白天 / 黄昏 / 夜间）

时间与场景解耦，每个场景都必须完整实现四种时间；切换时间时，场景的灯光、天空、阴影与装饰物状态都要发生对应变化，不允许只换色调不换内容。

1. 清晨：低角度青金色晨光、薄雾、长投影；营地灯将熄未熄、篝火只剩余烬、桌上出现早餐餐具、晾晒物带露水感高光。各场景专属表现：海崖有朝霞与刚刚出海的小帆船；松林有流动晨雾与鸟鸣般的光斑跳动；服务区有刚开灯的便利店与送货小车；避难所有刚换岗扫动的探照灯。
2. 白天：明亮柔和的正午光、干净饱和的色彩、短而清晰的阴影；灯具全部熄灭、天幕与遮阳棚投影清晰，出现炊烟、蒸汽等"白天活动"细节。
3. 黄昏（默认）：保留原始设计的核心氛围——日落金橙与海面蓝紫渐变、天边晚霞渐变、蓝调时刻、暖色车内灯光与冷色暮色海景的强烈对比。各场景专属表现：海崖串灯点亮、灯塔开始工作；松林变为逆光剪影与金色光斑；服务区招牌灯箱初亮、车流渐密；避难所探照灯与警示灯启动。
4. 夜间：月光与星空主导，环境呈深蓝紫色；所有灯光道具点亮并带柔和光晕——串灯、营地灯、车内灯、灯塔光束、便利店灯箱、售货机灯带、探照灯与警示红灯；车内暖光更突出，成为深夜中的温暖焦点。
5. 实现要求：时间以"光照预设 + 装饰物状态切换"实现，切换时有1~2秒的平滑光照过渡（交叉淡入淡出），不生硬跳变。

## 五、天气系统（晴朗 / 多云 / 小雨 / 浓雾 / 降雪）

天气同样与场景、时间解耦，任意组合均有效（如"夜间小雨的末日避难所""清晨浓雾的山间松林""黄昏降雪的海崖"）。天气影响光照强度、粒子效果与材质状态：

1. 晴朗（默认）：各场景的基准表现。
2. 多云：云量增加、光照柔化、云影在地面缓慢移动，风力略增。
3. 小雨：雨丝粒子、地面湿润反光与水洼涟漪、天幕与遮阳棚布料因积水微微下凹、屋檐滴水；夜间灯光在湿地面上拉出彩色反光。
4. 浓雾：远景逐层雾化、灯光产生扩散光晕、景深层次被压缩，营造静谧朦胧感。
5. 降雪：雪花粒子缓慢飘落、屋顶 / 天幕 / 树枝 / 护栏 / 桌椅顶部积雪、地面覆薄雪（服务区车位划线若隐若现）。
6. 实现要求：天气粒子与材质状态切换同样平滑过渡；天气与时间叠加时取综合光照（如夜间浓雾 = 更暗 + 更强光晕）。

## 六、UI 要求

1. 一套轻量控制界面，分组提供四个维度的切换：场景、车型、时间、天气；每组用"图标 + 文字"的分段按钮或卡片列表，当前选中态清晰。
2. 顶部或角落显示当前组合标题（如「山间松林 · 拖挂房车 · 夜间 · 小雨」）。
3. UI风格与三渲二美术统一：半透明磨砂玻璃质感、圆角、细描边、柔和阴影、轻快的悬停 / 选中微动效；整体小巧克制，不遮挡模型主体。
4. 提供"隐藏 / 呼出UI"入口，可回到纯观赏模式（呼应原始"无UI陈列感"的精神）。
5. 切换逻辑：场景与车型切换用短暂淡入淡出 / 滑动过渡；时间与天气切换用光照与粒子的平滑过渡；相机拖拽旋转 / 缩放状态在切换前后保持连续，不打断观看。

## 七、动效要求（保持"静止但活着"的节奏）

所有场景延续原始提示词的动效观感——整体像静止而精致的三维微缩世界，但带有恰到好处的细微动态：

1. 海崖：串灯轻微闪烁、天幕布料随风轻摆、海面波光流动、远处灯塔光束缓慢旋转、海鸟偶尔掠过、车内小夜灯呼吸明暗、野餐垫上的纸巾被风轻掀。
2. 山间松林：松针随风轻摆、林间光斑摇曳、溪水流光与落叶漂流、松鼠偶尔窜过枝头、吊床轻晃、篝火火焰跳动与火星升起、晨雾缓慢流动。
3. 末日避难所：探照灯光束缓慢扫动、警示红灯旋转、天线指示灯闪烁、发电机排出蒸汽、火堆火星上升、晾衣绳衣物飘动、微尘在光柱中飘浮。
4. 高速路服务区：公路主线车流灯光流动、便利店招牌灯箱循环微闪、售货机灯带常亮、雨棚下小旗飘动、行道树叶片轻摆。
5. 通用系统：天气粒子（雨 / 雪）、灯光呼吸统一节奏；布料类元素（天幕、吊床、挂毯、晾晒衣物、小旗）统一受风力参数控制，风力随天气变化。

## 八、技术约束与工程要求

1. 本机已安装 node 与 pnpm，使用 pnpm 作为包管理器；技术栈建议 Vite + Three.js（TypeScript 优先），纯浏览器运行，运行时不依赖网络。
2. 严禁使用 Blender 及任何外部建模软件 / DCC：所有几何体用代码程序化生成（基本体、Lathe / Extrude、实例化复用）；三渲二效果用卡通材质 + 渐变色阶 + 描边（反壳描边或后期描边均可）实现；所需贴图用 Canvas / SVG 程序化生成。
3. 性能目标：中端笔记本 60fps；重复元素（松树、礁石、集装箱、行道树、桌椅等）使用实例化，控制 Draw Call。
4. 架构上把场景 / 车型 / 时间 / 天气做成四套互相独立的注册表与数据模块（见2.5、3.6），公共系统（风力、粒子、灯光呼吸、描边、时间光照预设、天气材质状态）沉淀为可复用模块，支持后续持续扩展。
